# DeadZone - AI Coding Rules & Ticket Workflow

## Workflow States
`TODO` → `IN PROGRESS` → `IMPLEMENTED` → `TESTING` → `DONE` (or `REWORK`).

## Mandatory Pre-Coding Checklist
1. Every ticket must state: Status, Priority, Type, Objective, Requirements, Files to Create/Modify, and Acceptance Criteria.
2. An AI agent must inspect existing code, explain the plan briefly, implement ONLY the active ticket, test the changes, and record files modified before advancing.
